## 建议教学节奏

第一次课先完成00–01并让学生手算。02–05按传统视觉主线；06–08是深度学习入门。09–16可按项目选择，其中10–11需要先理解06的训练循环。17–18作为综合实践，要求学生提交输入、参数、中间图、输出、评价与失败案例。

统一图文结构为：学习目标 → 输入图与标签 → 小矩阵/张量 → 处理过程 → 输出图与指标 → 失败案例/局限 → 修改参数练习 → 来源。所有实际代码单元可在新内核顺序执行。
